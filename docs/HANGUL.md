# 확장 기능: 떠다니는 한글 자음·모음 검출·추적

담당: Pdint (Claude) · 브랜치 `claude/hangul` · 코드 `extensions/hangul.py`, `hangul_dataset.py`

화면 위를 떠다니는 한글 **자음·모음 하나하나를 객체로** 보고, 각각에 고유 ID를 붙여 추적하면서 어떤 자모인지 표시합니다.
단어를 읽는 OCR은 쓰지 않습니다. 검출기가 자모 40종을 바로 분류합니다.

## 1. 검출 대상 (40클래스)

| 구분 | 자모 | 개수 |
|---|---|---:|
| 기본 자음 | ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ | 14 |
| 쌍자음 | ㄲ ㄸ ㅃ ㅆ ㅉ | 5 |
| 기본 모음 | ㅏ ㅑ ㅓ ㅕ ㅗ ㅛ ㅜ ㅠ ㅡ ㅣ | 10 |
| 복합 모음 | ㅐ ㅒ ㅔ ㅖ ㅘ ㅙ ㅚ ㅝ ㅞ ㅟ ㅢ | 11 |

클래스 번호와 이름(로마자 자모 이름, 예: `giyeok` = ㄱ)은 `extensions/hangul.py`의 `JAMO` 표가 기준입니다.
순서를 바꾸면 가중치를 다시 학습해야 합니다.

## 2. 데이터: 직접 만드는 합성 데이터

떠다니는 자모의 추적 정답(ID)이 있는 공개 데이터나 주어진 영상이 없어, 정답을 아는 데이터를 `hangul_dataset.py`로 만듭니다.

* **검출 학습 이미지**: 배경(`sample.mp4` 프레임, 사진 폴더, 무늬) 위에 자모 3~14개. 글꼴·크기·색·외곽선·바탕 판(풍선·카드)·회전을 무작위로.
* **떠다니는 자모 영상** (MOT 형식): 자모 8~14개가 떠다니며 천천히 회전하고, 교차하고, 가림막에 가려지고, 화면 밖으로 나갔다 다시 들어옵니다.
  같은 자모가 여러 개 함께 나옵니다. ID별 자모는 `gt/objects.json`, 프레임별 회전 각도는 `gt/angles.csv`.
* **분할**: train / val / test를 따로 생성. 글꼴이 5개 이상이면 약 20%는 test에서만 씁니다.
* **회전 범위 ±45°** (`--rotation`).

## 3. 자모 추적이 어려운 점과 대응

| 어려운 점 | 대응 |
|---|---|
| **회전하면 다른 글자가 됩니다.** ㅏ를 180° 돌리면 ㅓ, ㅗ↔ㅜ, ㄱ↔ㄴ, ㅡ를 90° 돌리면 ㅣ | 회전을 ±45°로 제한 (이 범위에서는 원래 글자를 구분할 수 있음) |
| **좌우 반전 증강**을 쓰면 ㅏ가 ㅓ로 학습됩니다. | 학습할 때 `--fliplr 0` |
| 회전·가림 때문에 **프레임마다 검출 클래스가 바뀔 수 있습니다.** 기존 추적기는 클래스가 다르면 연결하지 않아 ID가 끊깁니다. | 추적은 클래스와 무관하게 위치·움직임으로 연결하고, 자모는 **트랙별 다수결**로 정합니다 (2단계) |
| **모양이 똑같은 객체**(같은 색 ㄱ 두 개)는 외형으로 구분할 수 없습니다. | 칼만 필터의 움직임 예측으로 구분. 기본판·개선판 비교 대상 |
| ㅡ, ㅣ처럼 **매우 얇은 자모**는 박스가 작아 검출이 어렵습니다. | 박스에 여유를 두고 생성, 클래스별 성능을 따로 확인 |

## 4. 진행 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 합성 데이터 생성기, 40클래스 검출기 학습 경로(`train_models.py hangul`), Colab 노트북 | 완료 (본 학습은 미실행) |
| 2 | `extensions/hangul.py`: 클래스 무관 추적 + 트랙별 다수결, GUI 표시(`자3 ㄱ`) | 예정 |
| 3 | 평가 스크립트: HOTA·IDF1·MOTA·IDSW, 프레임 단위/트랙 다수결 분류 정확도, 회전 각도별 정확도, 혼동이 잦은 쌍 | 예정 |
| 4 | 기본판·개선판 비교, 회전 범위(0°·±45°)에 따른 성능 변화, 실패 사례 분석 | 예정 |
| 선택 | 가까워진 자음+모음을 글자로 조합해 보여 주기 (ㄱ + ㅏ → 가) | 미정 |

## 5. 실행

```powershell
python hangul_dataset.py --output datasets/hangul
python train_models.py hangul --data datasets/hangul/dataset.yaml --fliplr 0 --epochs 50 --install
```

GPU 학습은 `colab/train_hangul.ipynb`를 씁니다. 결과는 `models/hangul_jamo.pt`와 학습 설정·성능 `models/hangul_jamo.json`입니다.

## 6. 한계

* 합성 데이터로만 학습·평가하므로 실제 촬영 영상(손글씨, 조명 변화 등)에서의 성능은 확인하지 못합니다.
* 회전이 ±45°를 넘는 자모는 다른 자모로 분류될 수 있습니다.
* 가시 비율(visibility)은 화면 경계와 가림막만 반영하고, 자모끼리 겹친 부분은 반영하지 않습니다.
